# Photo Placeholder Instructions for Anshika's Birthday Site 📸

Place real photos in this directory (`public/assets/photos/`) using the following filenames to replace the default placeholders:

- `anshika-hero.jpg` - Main hero photo of Anshika (optional)
- `memory-01.jpg` - Photo for Memory #01 (Sibling Shenanigans)
- `memory-02.jpg` - Photo for Memory #02 (The Reel Partner)
- `memory-03.jpg` - Photo for Memory #03 (Random Arguments)
- `memory-04.jpg` - Photo for Memory #04 (Tea Master Didi)
- `memory-05.jpg` - Photo for Memory #05 (Festival Magic)
- `memory-06.jpg` - Photo for Memory #06 (Best Friends Forever)

*Note:* If any photo file is missing, the site automatically renders a stylized custom SVG fallback card so the website always looks complete and beautiful!
